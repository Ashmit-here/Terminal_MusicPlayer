# Terminal_MusicPlayer
So basically a music player in terminal with features of a basic music player


so i made a terminal music player with the given features :
choosing songs with arrow keys 
seek +10sec/-10sec with arrow keys 
next track / previous track with keys
volume button and visualiser with keys
progress bar visualiser 
mute/unmute assigned to keys
autoplay 
loop (none,one song, one playlist)
shuffle play


the music player is working with vlc in terminal not afplay
